# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be direct about code, generous about people. Critique the change, never the contributor.
Harassment, personal attacks, and dismissiveness about someone's experience level are not welcome here.

## Scope

Issues, pull requests, discussions, and any space where you are representing the project.

## Enforcement

Report incidents privately to the maintainers (Security → Advisories is the only private channel until
a dedicated address exists). Reports are read by maintainers only. Consequences follow the Covenant's
enforcement ladder: correction, warning, temporary ban, permanent ban.

Maintainers are held to the same standard as everyone else.
